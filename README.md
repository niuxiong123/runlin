# 润林 · A股港股贵贱指南（移动版）

一个面向手机的 A股/港股"贵贱"择时辅助工具。把原离线网页重排成移动优先的响应式布局，
拆成 7 个模块（总览 / 市场贵贱 / 基金买卖 / 实证 / 历史回测 / 规律 / 方法），
首屏只看结论，按需下钻。

- 在线预览即开即用，**手机浏览器直接打开链接**即可查看。
- 联网时自动拉取最新 `data.json`；断网或本地打开时用**内嵌离线快照**，照常显示。
- 数据口径：腾讯历史月线 + 快照基线，**仅供学习研究，不是投资建议**。

## 部署（手机可访问）

## 自动更新数据
本仓库带了一套"自动更新"机制（`generate_data.py` + GitHub Actions）：
每个工作日约北京时间 15:30 自动跑一次，把新 `data.json` 提交回仓库，Pages 重新发布，
手机刷新即见新数据。

⚠️ **关于"真正的新数字"**：本仓库只带来了"算好的结果数据"，**没有**带来原版生成器的
算法。`generate_data.py` 默认处于**安全模式**——只复用现有 `data.json`，不伪造刷新时间、
不乱改买卖信号。要把它变成"真正用实时行情重算"，需要把你 **v3 原版生成器**里"产出 DATA
字典"的核心逻辑粘贴进 `generate_data.py` 的 `build_data()`（文件内已标 TODO），并在
`fetch_raw()` 补全 akshare 接口。接入后，脚本才会算出与你在本地一致的全新数据。

## 说明
- 本静态页本身**不连接股票行情接口**；"实时"= 拉取最新的 `data.json` 文件。
  要让数据按日程自动变成真实行情，靠上面的生成器 + Actions。
- 想要逐笔实时tick行情，需要额外接行情 API / 后端服务，不在本静态页范围内。
